    網路

    Gateway 是 UniFi Dream Machine（不支援 BGP）。網段和 zone 由 Terraform 管理（terraform/unifi/），自訂 zone 之間預設 Block，只開需要的 Allow。

    使用中的網段

    VLAN 網段 UniFi 名稱 Zone DHCP 用途 管理方式
    untagged 192.168.2.0/24 192.168.2.0 Internal True UniFi 設備、AP、PC、NAS、JumpServer、ESXi、vCenter terraform
    — 192.168.3.0/25 VPN Server（L2TP） Vpn — 遠端存取；Terraform provider 不支援 ui
    4 192.168.4.0/24 電視 Internal True 電視 terraform
    65 192.168.65.0/24 WIFI-192.168.65.0 Z-HOME True 家用 Wi-Fi（5 GHz） terraform
    3 192.168.66.0/24 WIFI-192.168.66.0 Z-HOME True 家用 Wi-Fi（2.4 GHz，IoT 相容，Tapo） terraform
    67 192.168.67.0/24 WIFI-192.168.67.0 Hotspot True 訪客 Wi-Fi terraform
    69 192.168.69.0/24 192.168.69.0 Z-LAB False OCP 節點、HAProxy、Infra VM terraform
    202 192.168.202.0/24 VLAN202 Z-MOD False 中華電信 MOD；純 L2，不經過 UDM terraform
    20 172.16.0.0/22 172.16.0.0/22-OCP — — vlan-only，OCP 測試用 none

    managed_by：terraform 由 Terraform 管理並自動比對；ui 只能在 UniFi UI 設定；none 不納入管理。

    規劃中的網段

    VLAN 網段 名稱 Zone 階段 用途
    72 192.168.72.0/22 HUB Z-HUB H0 Hub K8s 節點、MetalLB VIP、之後搬過來的服務
    — 192.168.121.0/24 K8S-SVC Internal Phase 1b OCP 非 HTTP 服務的 LB IP；靠 static route，不建 VLAN
    130 192.168.130.0/24 DB Z-DB 需要時 預留
    150 192.168.150.0/24 PC Z-ADMIN Phase 2 PC 從 192.168.2 拆出來
    — 192.168.190.0/24 VPN（WireGuard） Vpn 需要時 取代 L2TP
